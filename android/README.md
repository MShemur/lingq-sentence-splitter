# LingQ Fix (Android)

Built by `.github/workflows/android.yml` on every push to `android/`; each build is published as
release `v1.<run number>` with the APK attached.

## Install on the phone

1. Open https://github.com/MShemur/lingq-sentence-splitter/releases on the phone (signed in as MShemur).
2. Download `lingq-fix-1.N.apk` from the latest release and open it; allow installing from the browser.
3. In the app: ⚙ Settings → LingQ API key (https://www.lingq.com/accounts/apikey/) and language.
4. For in-app updates: a fine-grained GitHub token with access to this repository only and
   **Contents: Read-only** → paste it in ⚙ Settings → "GitHub-токен".

Newer versions then appear on the home screen as "Доступна версия … → Обновить".
