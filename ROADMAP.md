# План улучшений SatzLoop

Общий план для Android и веб-версии (iPad). Очередь переноса функций между платформами ведётся в `PORTING.md`.
Обновлено: 10.11.2026 (Android v1.66, web v1.28).

## Не делаем (решено)

- Статусы слов (новое / изучаю 1–4 / знаю), подсветка по статусам, счётчик известных слов.
- Свой словарь вместо подсказок LingQ.
- Карточки и повторение слов (SRS).
- Свой сервер для распознавания речи (Whisper на своём ПК или арендованном сервере): только облачные поставщики и Whisper на телефоне.

## Сделано: аудиоплеер с текстом и повтором

Работает на уроках LingQ, где есть аудио (Android и веб).

- Вкладка «Плеер»: окно с текущим предложением и соседними; полный текст, который идёт за аудио.
- Нажатие на слово ведёт к началу его предложения. Долгое нажатие открывает меню: перевод слова, перевод предложения, начало и конец повтора.
- Скорость 0,5–2,0×, ±5 с, двойное нажатие слева или справа = ∓5 с, к предыдущему или следующему предложению.
- Повтор (дриллинг):
  - это предложение;
  - весь урок;
  - только что прозвучавшие или следующие 30 с / 1 / 2 / 5 мин;
  - свой участок A–B;
  - пауза между повторами;
  - плашка повтора с кнопкой «стоп».
- Аудиозакладки, «Слушать все» (очередь уроков), мини-плеер, экран блокировки, виджет плеера (только Android).
- Статистика: чтение и аудио считаются отдельно (Android v1.61, на вебе в очереди).

## Дальше

### 1. Расшифровка аудио (несколько поставщиков)

Нужна для своих аудио без текста и для привязки по времени, если текст уже есть.

- Нужны отметки времени каждого слова.
- Поставщики (цены проверить при подключении):
  - Groq Whisper large-v3-turbo — самый дешёвый и быстрый, около 0,04 $ за час;
  - OpenAI whisper-1 или gpt-4o-mini-transcribe;
  - Deepgram, AssemblyAI, ElevenLabs Scribe — точные, с временем слов;
  - Gemini — текст хороший, время неточное, для синхронизации плохо;
  - Whisper на самом телефоне — бесплатно, но медленно; запасной вариант.
- Настройка как у ИИ: поставщик, ключ, модель. Ключи синхронизируются зашифрованными паролем синхронизации.
- Если текст уже есть (аудиокнига с текстом), расшифровка только для времени: слова расшифровки сопоставляются с текстом, показывается чистый текст.
- Дальше расшифровка идёт через уже существующие очистку текста и исправление разбивки на предложения, затем загружается в LingQ (или на свой сервер, когда он будет).

### 2. Импорт подкастов

- Поиск подкаста по названию (каталог Apple Podcasts: iTunes Search API, бесплатно, без ключа) или вставка ссылки на RSS-ленту.
- Подписки: список подкастов, новые выпуски отмечаются.
- Список выпусков: название, дата, длительность, описание. Выбор одного или нескольких.
- Выпуск: скачать MP3 из ленты → текст:
  - если лента даёт готовую расшифровку (тег `podcast:transcript`, бывает с временем) — взять её;
  - иначе расшифровка через выбранного поставщика (пункт 1).
- Дальше как обычный импорт: очистка, разбивка на предложения, урок в курсе LingQ с аудио. Загрузку аудио в урок LingQ через API проверить отдельно.
- Где брать немецкие подкасты: DW (Langsam gesprochene Nachrichten, Top-Thema), ARD Audiothek, Deutschlandfunk, любые с открытой RSS-лентой. Подкасты только для Spotify или Audible (DRM) не поддерживаются.

### 3. Свой сервер для уроков (отложено)

- Cloudflare: Workers (код), D1 (база), R2 (файлы). Для одного человека бесплатно: 10 ГБ ≈ 350 часов MP3.
- Там будут лежать уроки (текст, предложения, переводы), аудио, заметки, закладки.
- Синхронизация переедет туда, ветка `sync` на GitHub станет не нужна.
- Если нужно строго в Германии: Hetzner (~5 € в месяц) или VPS на Strato.

### 4. Мелкие улучшения (по желанию)

- Таймер сна в плеере.
- Цвета плеера по обложке урока.
- Android: кнопки наушников «назад / вперёд» = ±5 с (на вебе уже сделано в v1.25).
